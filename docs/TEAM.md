# Equipe & Acesso — Aurora

Este documento lista o modelo de equipe e orientações para convites e participação.

Modelo sugerido
- 4 líderes (um por core): cada líder assume responsabilidade por seu conjunto de auroras.
- Cada líder pode convidar até 3 colaboradores por core (crescimento gradativo).

Convite de clientes
- Se os clientes não têm conta GitHub, você pode:
  - Convidá-los por e-mail (Settings → Manage access → Invite collaborators). Eles precisarão criar conta para aceitar.
  - Ou receber feedback por formulário e registrar issues em nome deles.

CODEOWNERS
- Para usar CODEOWNERS precisamos dos usernames GitHub. No momento, deixamos placeholders em `.github/CODEOWNERS` — atualize com `@username` quando estiverem disponíveis.
